# NoteHub

A React + TypeScript app for creating, searching, paginating and deleting notes, built with Vite.

## Stack

React, TypeScript, TanStack Query, Axios, Formik + Yup, React Paginate, use-debounce, CSS Modules, modern-normalize.

## Getting started

```bash
npm install
cp .env.example .env   # then set VITE_NOTEHUB_TOKEN
npm run dev
```

Get a personal token at https://notehub-public.goit.study/api/docs.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build
- `npm run format` — format the code with Prettier
